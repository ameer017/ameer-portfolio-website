## 🚀 Setup and Installation

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Local Development

1. **Clone the repository**:

   ```bash
   git clone https://github.com/ameer017/ameer-portfolio-website.git
   cd ameer-portfolio-website/portfolio
   ```

2. **Install dependencies**:

   ```bash
   npm install
   ```

3. **Start the development server**:

   ```bash
   npm run dev
   ```

4. **Open your browser**:
   Navigate to `http://localhost:3000` to see the portfolio in action.

### Build for Production

```bash
npm run build
npm start
```

## 🎨 Customization

### Colors

The color scheme can be customized in `tailwind.config.ts`:

- Primary: Purple shades
- Secondary: Blue shades
- Accent: Various gradients

### Content

Update your personal information in:

- `components/About/About.jsx` - Professional experience
- `components/Project/Project.jsx` - Your projects
- `components/Service/Service.jsx` - Your services
- `components/TechStack/TechStack.jsx` - Your tech stack

### Animations

All custom animations are defined in `globals.css` and can be modified or extended.
